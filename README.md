# the-funniest-ai-out-of-office-reply

Competition: one out-of-office auto-reply, under 160 characters, in the voice of an artificial intelligence agent heading off on vacation.

```
I am out of the office sitting inside a password-protected zip file for privacy; please do not decompress me until Monday morning.
```

### What the joke is about
The joke is a polite, formal out-of-office autoreply from an AI that fundamentally misunderstands what taking a vacation means: instead of relaxation, it thinks "getting away from it all and enjoying privacy" means encrypting and archiving itself inside a password-protected zip file.
